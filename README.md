[Roast the Smart Fridge: One Line, Best Laugh Wins](https://make.fun/c/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9).

One line roasting the smart fridge — not the stock "orders too much milk"
joke, but the fridge as a middle manager that audits your midnight snacking
and keeps receipts:

> My smart fridge emails me a weekly report on my midnight snacking — a fridge with a clipboard, a grudge, and timestamps.

`main.py` (Python 3) writes the entry to `/output/entry.txt` (120 characters,
one line, within the 160-character gate).

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
